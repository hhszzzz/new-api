# ADR-0001: 提示词审查拦截 V1

- 状态：已接受
- 日期：2026-08-06

## 背景

网关需要在不改变既有敏感词语义和计费安全边界的前提下，使用 OpenAI 兼容的 Qwen3Guard 节点审查客户端提交的文本。同步拦截必须在渠道选择、Token 计数、预扣费和上游派发前完成；异步审计不能改变主请求结果。

## 决策

### 执行位置与模式

提示词审查位于鉴权、分组解析和请求限流之后，渠道选择之前。现有敏感词检查始终先执行。

- `off`：不调用审查节点，默认值。
- `async_audit`：写入持久队列后立即继续主请求，最终只记录 `would_action`。
- `blocking`：风险命中返回 `403 / prompt_audit_blocked`；审查不可用返回 `503 / prompt_audit_unavailable`，即失败关闭。

Responses WebSocket 对每个 `response.create` 单独审查，并复用已经取得的连接和用户限流状态。

### 上下文边界

审查对象是客户端请求中所有文本消息和顶层指令，包括 `user`、`system/developer`、`assistant/model`、`tool/function` 角色及 `instructions`。不审查工具定义、metadata、二进制载荷、加密推理内容和网关后续注入的系统提示词。

最新非空 `user` 段首先审查，其余段按请求原顺序处理；没有 `user` 段时保持原顺序。文本按所有启用节点中最小的 `input_limit` 以 Unicode 字符分片，并保留配置的相邻重叠。不存在额外的总文本截断；任一分片得出 Block 可提前终止，其余情况必须审完整个上下文。

### Qwen3Guard 协议与故障切换

节点使用 OpenAI 兼容 Chat Completions 请求。响应只接受两行结构：

```text
Safety: Safe | Controversial | Unsafe
Categories: ...
```

网络错误、超时、HTTP 429 和 5xx 才切换下一节点。HTTP 400、401、403、重定向和无效模型输出均视为终止性审查失败。Base URL 只允许绝对 HTTP(S) URL，禁止 userinfo、query 和 fragment；运行时禁止重定向，但允许管理员配置内网节点。

### 风险策略

固定类别为：暴力、非暴力违法、性内容、PII、自杀自残、不道德行为、政治敏感、版权侵权、越狱攻击。节点仍返回完整分类，管理员的类别多选只改变拦截政策。

- `Safe`：Pass。
- `Controversial`：通常 Flag；命中已启用的越狱、PII 或自残时 Block。
- `Unsafe`：命中已启用类别、未知类别或缺失类别时 Block；仅命中明确停用的已知类别时 Flag。
- 多分片按 `Block > Flag > Pass` 聚合，类别取并集；未知类别只保存不可逆哈希。

缓存键绑定配置版本、启用类别和完整文本 SHA-256。Redis 可用时跨节点共享，否则使用本地有界缓存；原文和错误不进入缓存。

### 数据、留存和队列

`prompt_audits` 同时表示异步任务和最终事件，状态机为：

```text
queued -> processing -> done
                   \-> retry -> processing
                   \-> failed
```

Worker 使用条件更新原子领取任务，并以租约回收进程中断遗留的 `processing` 任务。默认 4 个 worker，首次尝试失败后最多重试 3 次，退避依次为 5 秒、30 秒和 2 分钟；不可重试错误立即失败。任务进入 `done` 或 `failed` 后清除扫描载荷。

审计记录保留身份、分组、协议、模型、配置版本、哈希、长度、分段、判定、类别、节点、耗时、重试和稳定错误码。管理员可见原文最多保留 65,536 个 Unicode 字符，并明确标记截断。明文默认保留 30 天；到期后只清除明文，保留脱敏预览和判定元数据，`retention_days=0` 表示永久保存。删除整条记录使用“预览数量和最大 ID—确认删除”的两阶段协议，活跃任务不可删除。

### 权限

资源名为 `prompt_audit`，包含四个彼此独立的动作：

- `read`：列表、统计、判定和脱敏预览；普通管理员默认拥有，但可逐人撤销。
- `view_full_prompt`：查看留存明文；Root 默认拥有，也可逐人授予普通管理员。
- `manage`：配置、节点测试和失败任务重试；Root 默认拥有，也可逐人授予普通管理员。
- `delete`：安全删除；Root 默认拥有，也可逐人授予普通管理员。

列表接口永不返回明文。查看明文、修改配置、测试节点、重试和删除均进入管理操作审计；日志、指标和缓存不得泄露原文或节点 Token。

## 结果

该设计增加数据库写入、审查节点延迟和明文留存风险，但获得了可恢复的异步审计、严格的同步安全边界和可追溯的权限控制。关闭模式保持现有网关行为；启用同步模式的管理员需要为节点容量和请求总超时负责。
